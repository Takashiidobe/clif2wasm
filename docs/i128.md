# i128 support

CLIF `i128` values are represented as `(lo: i64, hi: i64)` in WebAssembly. The translator lowers add/sub with carry or borrow, wrapping and high multiply, bitwise operations, shifts and rotates, signed and unsigned comparisons, min/max, div/rem, overflow flags including carry/borrow inputs, negation, bitwise not, bit counts, extension/reduction, saturating float conversions, and memory access. Integer-to-float conversion supports `f32` and `f64` with round-to-nearest, ties-to-even.

The following valid or potentially valid CLIF forms remain unsupported and return an unsupported-opcode diagnostic:

- Trapping float-to-`i128` `fcvt` operations.

`iabs`, saturating arithmetic, rounded average, and rounded saturating multiply are vector operations in CLIF and do not accept scalar `i128`. `umul_overflow` and `smul_overflow` explicitly exclude `i128`.
