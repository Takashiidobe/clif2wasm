# i128

CLIF `i128` is a `(lo: i64, hi: i64)` pair. Add, sub, negation, shifts,
comparisons, div/rem, bit counts, extension and reduction, memory access and
saturating float-to-`i128` are all lowered, including carry/borrow inputs and
overflow flags. Int-to-float supports `f32` and `f64` with round-to-nearest,
ties-to-even.

## Unsupported

- Trapping float-to-`i128` `fcvt`: Wasm has no 128-bit trapping conversion.
- Trapping float-to-`i8`/`i16`: Wasm traps only for `i32` and `i64`.
- `f16` and `f128`: Waffle has no scalar type, so type mapping fails.
- `iabs`, saturating arithmetic, rounded average, rounded saturating multiply:
  vector-only in CLIF.
- `umul_overflow`, `smul_overflow`: exclude `i128`.
