# Vendored Waffle

This module vendors [Takashiidobe/waffle](https://github.com/Takashiidobe/waffle) at commit `bb4ed2c0b5cf1bea85884e9106a65d297e2d53f7`.

Its Rust 2018 crate source is integrated here as a module in the Rust 2024 `clif2wasm` crate. Internal crate paths and edition-sensitive patterns are adapted for that integration. The upstream license is in [LICENSE](LICENSE).
